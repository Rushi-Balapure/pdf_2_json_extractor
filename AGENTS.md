# Project Context

This repository is a Python package named `pdf_2_json_extractor`. It extracts structured text from PDF files into JSON, with heading detection based on PDF font sizes and paragraph grouping based on layout positions.

## Main Entry Points

- `pdf_2_json_extractor/__init__.py`
  - Public package API.
  - Exposes `extract_pdf_to_dict(pdf_path)` and `extract_pdf_to_json(pdf_path, output_path=None)`.
  - Version is currently `1.3.1`.
- `pdf_2_json_extractor/cli.py`
  - CLI entry point for the `pdf_2_json_extractor` console script.
  - Also runnable as `python -m pdf_2_json_extractor.cli`.
  - Supports PDF path, `-o/--output`, `--compact`, and `--version`.
- `pdf_2_json_extractor/extractor.py`
  - Core extraction logic.
  - `PDFStructureExtractor.extract_text_with_structure()` validates the PDF, analyzes font sizes, extracts a title, creates sections, groups paragraphs, and returns the JSON-ready dictionary.
- `pdf_2_json_extractor/config.py`
  - Runtime configuration dataclass.
  - Reads selected `PDF_TO_JSON_*` environment variables when each `Config` instance is created.
- `pdf_2_json_extractor/exceptions.py`
  - Package exception hierarchy: `PdfToJsonError`, `PDFProcessingError`, `InvalidPDFError`, and `PDFFileNotFoundError`.

## Core Extraction Flow

1. `extract_pdf_to_dict()` or `extract_pdf_to_json()` creates a `PDFStructureExtractor`.
2. `extract_text_with_structure()` checks that the input path exists, then opens it with PyMuPDF.
3. `analyze_font_sizes()` builds a font-size histogram from up to `Config.MAX_PAGES_FOR_FONT_ANALYSIS` pages.
4. Font sizes larger than the dominant body font and above `Config.MIN_HEADING_FREQUENCY` become heading levels `H1` through `H6`.
5. `_extract_title()` picks the largest text span on the first page.
6. `_iter_lines()` yields line dictionaries with text, page number, max font size, and vertical bounds.
7. If no text layer is found, `_iter_lines_ocr()` attempts PyMuPDF OCR using Tesseract.
8. Heading lines start new sections; non-heading lines are buffered and grouped into paragraphs by `_group_paragraphs()`.
9. The result includes `title`, `sections`, `font_histogram`, `heading_levels`, and `stats`.

## Tests

- Test directory: `tests/`
- Main test files:
  - `tests/test_api.py`: public API behavior and JSON output.
  - `tests/test_cli.py`: subprocess-based CLI tests.
  - `tests/test_extractor.py`: extractor, font analysis, paragraph grouping, heading classification, title extraction, and OCR fallback.
  - `tests/conftest.py`: fixtures for real PDFs, invalid PDFs, empty files, output paths, and scanned-like OCR PDFs.
- Real PDF fixture:
  - `papers/1751-0473-7-7.pdf`
- OCR fallback tests require `tesseract`; they skip if it is unavailable.

## Packaging And Dependencies

- `pyproject.toml` is the main modern package metadata file.
- `setup.py` is also present and duplicates some metadata.
- Runtime dependency is PyMuPDF (`pymupdf>=1.24.0` in `pyproject.toml`).
- `requirements.in` and `requirements.txt` are for development/tooling pins generated by `pip-compile`.
- Console script is configured as:
  - `pdf_2_json_extractor = "pdf_2_json_extractor.cli:main"`

## Code Style Notes

- The package uses Python 3.8+ metadata, but the code already uses modern type syntax like `str | None` and `dict[str, Any]`.
- `ruff` config lives in `pyproject.toml`.
- Existing line length is 120.
- Keep changes small and compatible with the current API shape unless the task explicitly asks for a larger refactor.
- Prefer extending existing helpers in `PDFStructureExtractor` over adding a parallel extraction pipeline.

## Known Project Quirks

- `README.md`, `pyproject.toml`, and `setup.py` still contain placeholder GitHub URLs using `your-username`.
- `README.md` documents several configuration environment variables that are not currently implemented in `Config`; only these are active:
  - `PDF_TO_JSON_MAX_PAGES_FOR_FONT_ANALYSIS`
  - `PDF_TO_JSON_MIN_HEADING_FREQUENCY`
  - `PDF_TO_JSON_MAX_HEADING_LEVELS`
- `tests/conftest.py` contains a casual phrase in a docstring; avoid broad cleanup unless asked.
- `.codex` currently exists as an empty read-only file, not a directory.
